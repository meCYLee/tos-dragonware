
# 神魔之塔龍刻圖鑑

一個方便瀏覽及記錄收藏的《神魔之塔》龍刻與武裝龍刻圖鑑。

## 開啟網站

### [前往神魔之塔龍刻圖鑑](https://mecylee.github.io/tos-dragonware/)

使用手機、平板或電腦瀏覽器即可使用，不需要下載其他程式。

## 主要功能

- 收錄 **3,910 枚龍刻**，包含 463 枚一般龍刻及 3,447 枚武裝龍刻
- 目前更新至2026.6版本（魔女永夜ΙΙ）
- 依編號、名稱、技能、裝備角色或角色系列搜尋
- 依一般／武裝、龍刻模式、系列來源及收藏狀態篩選
- 武裝龍刻可依「自家／合作」及裝備角色所屬系列篩選
- 每頁顯示 25 枚龍刻，可使用上一頁、下一頁或輸入頁碼快速跳轉
- 查看龍刻技能、武裝能力及裝備條件
- 使用電子郵件與密碼建立個人帳號
- 記錄已擁有、未擁有或尚未標記的龍刻
- 登入後跨裝置同步個人收藏
- 匯出及匯入 JSON 收藏備份
- 從五欄遊戲背包影片辨識龍刻，確認結果後批次更新收藏
- 支援加入 iPhone、iPad 及 Android 主畫面

## 如何使用

1. 開啟[正式網站](https://mecylee.github.io/tos-dragonware/)。
2. 使用上方搜尋或篩選功能找到想查看的龍刻。
3. 點擊「查看詳情」閱讀技能、武裝能力及裝備條件。
4. 註冊並登入帳號後，即可標記自己的收藏。
5. 建議定期使用「匯出備份」另外保存收藏副本。

## 帳號與收藏同步

網站使用電子郵件與密碼登入。登入後，收藏會同步到你的個人帳號，之後在其他手機或電腦登入同一帳號即可繼續使用。

網路暫時中斷時，收藏變更會先保存在目前裝置，恢復連線後再嘗試同步。

## 從遊戲影片辨識收藏

你可以上傳自己的五欄遊戲背包錄影。影片只會在目前的瀏覽器中處理，不會上傳到網站伺服器。

辨識完成後，網站會先列出結果供你檢查；只有在你確認後，才會將結果寫入個人收藏。實際辨識結果仍可能受影片畫質、捲動速度及畫面比例影響。

## 加入手機主畫面

### iPhone／iPad

使用 Safari 開啟網站，點選「分享」→「加入主畫面」→「加入」。

### Android

使用 Chrome 開啟網站，點選右上角選單→「加到主畫面」或「安裝應用程式」。

## 圖片狀態

目前 3,909 枚龍刻已有可顯示圖片。部分圖示仍使用遊戲影片截圖，8023「燎原毒螫龍輝」的正確圖片仍待補充。

## 隱私說明

- 遊戲影片只在使用者自己的瀏覽器處理，不會上傳到 Supabase。
- 雲端只保存帳號識別及使用者確認的收藏狀態。
- 每位使用者只能讀寫自己的收藏資料。
- 收藏備份可能反映個人遊戲進度，分享前請自行確認內容。
