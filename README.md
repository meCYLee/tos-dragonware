# 神魔之塔龍刻圖鑑

一個響應式的《神魔之塔》龍刻與武裝龍刻圖鑑，可依編號、類型、模式、系列來源、角色系列及收藏狀態進行搜尋與篩選。

本專案是非官方粉絲工具，與《神魔之塔》官方及 Mad Head Limited 無關。遊戲名稱、圖片及相關資料的權利屬原權利人所有。

## 功能

- 收錄 3,894 筆一般龍刻與武裝龍刻資料，所有項目皆有配圖
- 依編號由小到大或由大到小排序
- 依龍刻類型、模式及收藏狀態篩選
- 武裝龍刻可依「自家／合作」來源及裝備角色所屬系列篩選
- 搜尋編號、名稱、技能、適用角色或角色系列
- 每頁顯示 25 筆，可使用上一頁、下一頁或輸入頁碼快速跳轉
- 查看龍刻技能、武裝能力與裝備條件
- 使用電子郵件與密碼註冊、登入及重設密碼
- 登入後記錄已擁有或未擁有，並跨裝置同步
- 離線時暫存變更，恢復連線後自動重試
- 將收藏紀錄匯出及匯入為 JSON 備份
- 每位使用者可在瀏覽器上傳自己的五欄遊戲背包影片，核對辨識結果後批次同步到個人收藏
- 響應式介面：桌面每列 5 張、平板每列 3 張、手機每列 2 張

## 使用方式

直接開啟 `index.html` 即可瀏覽。帳號與跨裝置同步使用 Supabase；尚未設定時會保持停用，圖鑑瀏覽不受影響。
登入後，收藏會同步至自己的 Supabase 帳號；瀏覽器同時保留帳號專屬快取與離線待辦。JSON 匯出仍可作為額外備份。

## 隱私提醒

- 每位使用者的影片只會在自己的瀏覽器處理，不會由網站上傳到 Supabase；雲端只保存使用者確認的收藏狀態。
- 請勿將原始遊戲錄影、帳號畫面或個人收藏備份提交到公開 Repository。
- 收藏備份可能反映個人遊戲進度，分享前請自行確認內容。
- 雲端只保存使用者修改過的龍刻識別碼與收藏狀態；資料表以 Row Level Security 隔離帳號。
